# Logo Ponte en Quatro: llenado

El logo blanco aparece como contorno y se llena de abajo arriba como un vaso, con la superficie ondulando. Al final queda idéntico al PNG original.

- `logo-llenado-4k.mov`: 2160×3840, 3 s, 30 fps, fondo transparente (QuickTime Animation, el formato que lee CapCut en Mac). Se coloca encima del vídeo sin croma.
- `logo-llenado-vista-previa.mp4`: vista previa sobre fondo oscuro.
- `logo.png`: logo original.
- `llenado.py`: genera el .mov (`pip install numpy pillow scipy` y `python3 llenado.py`).
